# 鼓与 Bass，先把地基搭稳

## 01 鼓与 Bass，先把地基搭稳

先关系，后音色。让低频有重量，让节奏有轮廓。

先听一段主歌和一段高潮：谁负责落点，谁负责延续，谁负责推进？

沿着 4 条线排查：音量平衡 → 时间与极性 → 频率分工 → 前后层次。

不要一上来，把每件乐器都调得又大又亮。

操作：先只听 Kick、Bass、Snare，找到歌曲的重心。

## 02 第一步：平衡先过关

一个推子能解决的事，先不交给 EQ。

把 Kick 调到舒服、留有余量的位置，再慢慢加入 Bass；同时出现时，仍能分清落点与音符吗？

再加入 Snare。让它撑起节奏重音，但别默认所有歌都要 Snare > Kick。

检查轨道、处理器与总线的峰值。不存在通用的“Kick 必须 −10 dBFS”。

操作：以相近听感响度比较。整体太满，就回调相关轨道／组的电平，再检查前级处理器。

图注／限制：两个完全相同、同相正弦相加才是 +6.02 dB；实际乐器叠加不固定增加这个值。

## 03 低频变薄，先分清原因

遮蔽、相消、尾音堆积，需要不同的处理。

加入 Bass 后 Kick 难辨：可能是遮蔽。两者重叠时低频明显减少：再检查极性与时间关系。

Polarity 反转是上下翻转；Delay 是沿时间移动。一次反相不等于全曲“相位对齐”。

对比多个音符、多个鼓点；若只是某一击更大，别急着保留。先考虑音色、尾长与编曲避让。

操作：保留让整段低频更稳定、节奏更自然的选择。避免为对齐一个波峰破坏 groove。

图注／限制：数学示意：5 ms 对 50 Hz 是 90°，对 100 Hz 是 180°；实际 Kick / Bass 不是两条固定正弦。

## 04 频率是线索，不是处方

先找到“它是什么”，再决定“让它往哪走”。

Kick 的重量不固定在 100 Hz。先听基音／共振区域、尾长和击打轮廓，再决定保留哪一部分。

Bass 会换音：E1 ≈ 41.20 Hz，A1 = 55 Hz。对一个音有效的固定削减，可能伤到另一个音。

Analyzer 帮你定位；频谱重叠不能单凭画面判成遮蔽或相消。最终回到整段试听。

操作：若 Kick 在 800 Hz–2 kHz 显硬，可先试约 −1 至 −2 dB 的宽 Bell，再匹配响度旁通比较；不硬就不削。

图注／限制：官方 Pro-Q 4 图的轨道名为 Guitar，预设 Equalize 4；只解释界面，曲线不是鼓／Bass 推荐设置。

## 05 让 Bass 在小音箱也有形

低频负责重量，谐波帮助辨认音高与轮廓。

A1 的基频是 55 Hz；110、165、220 Hz 是它的第 2、3、4 阶谐波。音高变了，这组位置也跟着变。

小音箱听不清 Bass，别只继续推最底下。先判断已有谐波是否足够，也可在 800 Hz–2.5 kHz 寻找音符轮廓。

若有独立高频 Bass 层：先对齐音乐起音与时值，再从较小电平慢慢加入；听起来像同一声部的纹理即可。

操作：用实际小音箱复核，同时回到全频监听：轮廓增强了，低频是否仍自然？

图注／限制：示意振幅人为设定；不是实测频谱，也不承诺任意小音箱能重放所列频率。

## 06 Snare 的厚度与空间，分开管

鼓的本体要站住，混响才有地方落。

先听本体：约 300 Hz 可作厚度搜索起点；约 1 kHz 若显硬或有突出共振，再局部试削。

空间太抢时，先减少 Send 或缩短尾声，再检查 Reverb Return 的 2–3 kHz 是否拥挤。

削去击打区后，抬 10 kHz 只能改变另一段亮度，不能等价“补回”原来的清晰度。

操作：用独立 Send / Return 管理 Snare 的 Reverb。主路保留本体，返回通道单独调音量与 EQ。

图注／限制：频率均为试听起点；常规并行 Reverb 设为 100% Wet。不是所有 Snare 都要添加混响。

公开来源：S08、S11

## 07 亮，不必每一下都扎耳

Hi-hat、Cymbal 与大打击乐，要服务歌曲层次。

先把高频打击乐推子稍收，再听节奏是否仍连贯；不要把“能听见”变成“永远最突出”。

若只有重击刺耳，试动态 EQ；若整段都太亮，再考虑静态 EQ。5–8 kHz 只是可能的搜索区。

大打击乐要有体积，但别用无限加低频换气势；让 1–3 kHz 的硬度、尾长与进入时机配合高潮。

操作：与人声、Snare 一起听。保留需要的身体感，避免高通削过头后只剩尖锐边缘。

图注／限制：没有固定的镲片／打击乐削减频率；体积、亮度与情绪是整段关系。

公开来源：S08

## 08 最后，用一段音乐验收

整段通过，比某一击“巨大”更重要。

① 低音量听：Kick 落点、Bass 音符、Snare 重音都能跟住吗？

② Mono 听：合并为单声道后，低频与高频 Bass 层有没有异常变薄？

③ 换段落、换音符：处理是否稳定？高潮里镲片有没有盖过主角？

④ 匹配响度旁通：改善来自关系更清楚，还是只是更响？最后检查输出余量。

操作：一次只解决一个已听到的问题。没有问题的频段，不必按表动刀。

图注／限制：本套数值用于说明与起步试听；没有工程音频，因此不构成实测结论。
