## 事实与术语

- Attack 使用“建立衰减的响应速度”，未写成等待时间或恒定斜率。
- Release 区分恢复窗口、音节起点间隔和标称时间；未使用按歌曲快慢划定禁区的规则。
- 模型在 dB 域对 GR 做简化平滑，所有 τ 均标为模型常数；不当作 Pro-C 3 旋钮校准值或真实音频测量。
- 10 ms 的两条 Attack 模型值为 5.19 / 1.70 dB；180 ms 的 Release 剩余值为 0.99 / 3.29 dB；计算与图上点位一致。
- 80 BPM 十六分音符 187.5 ms、140 BPM 四分音符 428.6 ms 使用同一线性时间轴。它们是起音间隔，非 Release 预设。
- GR 用正值表示衰减深度，并与输出电平、主观响度区分。
- Pro-C 3 官方截图的 Nice Pumping 预设与 Pumping 风格均准确照录。RELEASE 旁 AUTO 呈灰色，GAIN 旁 AUTO 呈黄色；不把两个控件都写成“已开启”。
- Auto Gain 不承诺严格响度匹配；旁通比较要求尽量匹配主观响度。
