一句人声，一次只改一项
试听练习 · 产品功能：FabFilter Pro-C 3 Help · 图片 © FabFilter
1 循环一句，带伴奏确认问题
包含强弱、连续字头与句尾，先知道自己要听哪里。
2 固定条件，让比较可听懂
同一风格，固定 Knee / Lookahead / Hold； 学习时暂关 Auto Release / Auto Gain，先不叠 DRY。
3 先听 Attack
例如比较 5 与 30 ms，听字头是否变钝或过尖。
4 再听 Release
例如比较 80 与 250 ms，听句尾起伏与下一字。
每次 A/B，手动匹配响度
Auto Gain 不保证严格响度匹配。 尽量排除“变响了”的影响， 再放回伴奏判断。
数值是练习对照点，不是预设，也不是前页的模型 τ。 官方局部仅定位控件；不要照抄截图状态。

用听到的问题，决定下一步
试听方向：FabFilter / iZotope / Ableton · 详见研究报告
听现象，再选变量；没有必须达到的 GR 数字。
字头变钝
试慢一点的 Attack；也查持续 GR 是否太深。
起音尖、爆破突出
试快一点的 Attack，或先做局部电平整理。
呼吸或音量细碎起伏
试慢一点的 Release，或减少压缩量。
下一字发闷
看剩余 GR；试快一点的 Release 或较浅压缩。
停在：字头合适、字身稳定、下一句自然。
这些是试听方向，不是保证。 连贯控制可以保留一些衰减，GR 不必每次归零。
