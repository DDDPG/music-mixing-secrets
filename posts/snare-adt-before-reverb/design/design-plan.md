# 军鼓 ADT 图文独立设计计划

已阅读完整研究报告、ARTICLE、page-plan、真实原图与裁切、三张解释 SVG 和数据，随后制定本计划。以不可变 V3 实际 HTML / production_spec / 全尺寸图校准，不修改基准。

## 决策
八页。真实插件的高纵横比与 SRC/ADT 长条控件需要独立空间，因此把控件拆成「时间/LFO」与「Pan/Level」两页；数学完整梳状曲线保留在研究报告，移动端第七页以确切数值和邻近限制语说明风险，给完整链路试听留出主导位置。这是由内容决定的八页，不复制 V3 旧八页故事。

`production_spec.json` 是本轮可实现的权威几何与逐字文案。可作字体实测后的局部换行/等量位移，但不能自动缩字、删限制语或让箭头越过正文。图片路径相对 topic_01 根；HTML 位于下级目录时调整相对路径，不修改像素。所有图在页面尺度重建，不整张缩小原 SVG。

1. 完整真实产品图为封面主体。明确拓宽的是空间支路；官方展示数值不构成教程参数。
2. 从上到下的并联路由：黑色直达、蓝色效果；SRC+ADT 一起入全 Wet Reverb，再并回 Mix Bus。
3. 两个宽幅原像素裁切：时间区与 LFO。相对提前/滞后、Bars 与 Hz、人声 Quick Start 边界就近写清。
4. 两条真实 SRC/ADT 界面长条与右侧解释列。Pan 与 Level 分开听；Drive 不是 Level；SRC 不等于外部纯干声。
5. 共用 0–40 ms 线性时间轴，0/20/32 ms 对齐比例。避免使用假波形或「实测」外观。
6. 两种混响输入结构的非产品化示意，保留不同算法的限制、Pro-R 2 例证和 Reel ADT 的 Input Source 注意事项。
7. 返回 Solo → 全曲 Stereo → 全曲 Mono 的大字动作清单，附 12 ms 理想梳状模型风险与停止条件。
8. 主题收束、真实仓库地址、短 BibTeX HTML 引用。author 精确为 `{Kangdi, Wang}`；链接可点击，不加未经核验专题路径或二维码。

## 风格与细节
白底、#f5f5f7 分组、#1d1d1f 正文、#0066cc 关键路径、#697887 比较线；Noto 400/600，正文36–38，解释标签30–36，限制28–30，来源26。安全线72–1008。只给有明确语义的段落浅灰底和细线；无渐变、假窗口、装饰波形、大色块或重复卡片。真实界面保留原色。编号、线重和留白用于分组，不为装饰。

## 验收
每页全尺寸与360px手机预览肉眼复核。检查图片比例与状态、路由箭头、时间比例、长中文行、英文控件换行、字形与页脚。每条源图说明和数学限制语不能挪到另一页。引用 CSS 必须限定 `.citation-page`，尤其 h1/pre，避免污染正文。来源与权利限制继续保留，厂商公开转载权利仍未核实。
