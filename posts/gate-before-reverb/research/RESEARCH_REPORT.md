# 混响一开就糊？先管住入口

## 故事与判断
混响听起来拖沓，有时并非房间太长，而是鼓的串音、录音底噪、房间声和不需要的源尾音不断进入效果器。把 Gate 放在混响前，可以限制送入混响的低电平内容；已经建立的混响仍能自然衰减。这里的“干净”指更有选择地激励混响，不是消除所有噪声，也不是保证所有声音更好听。

关键首先是路由。让原始轨道继续走 Dry 主路；从 Send 分出一条支路，在 Return 上依次放 Gate → Reverb，并把并行混响设为纯 Wet。这样只修剪混响入口，不截短主路原声。若把 Gate 放在原轨分流之前，Dry 也会改变。共享 Return 会让所有送入声源一同触发 Gate；需要独立判断时给目标声源单独一条效果支路。

Gate → Reverb 与 Reverb → Gate 不能互换。前者改变输入，后者直接包络处理已经产生的混响输出。如果目标是明显截尾的 gated reverb，后者才是直接路径。前级 Gate 关闭时，混响内部已经积累的能量不会因此瞬间清零。两种处理都可用，选哪个取决于要控制“谁进入”还是“何时结束”。

## 用一个可复核例子理解
以下只是假设检测包络，不是音频实测，也不是任何插件预设。强事件峰值 −12 dBFS；不想送入的持续尾段为 −40 dBFS；开门阈值设为 −24 dBFS；关门阈值设为 −30 dBFS。假设事件已使 Gate 开启，检测值下降到 −27 dBFS 时仍保持开门，下降到 −32 dBFS 才满足关闭条件。开关阈值差 6 dB 就是示例中的 hysteresis。若没有这段差值，信号在单一阈值附近摆动时更容易反复开关。

时间控制接着决定是否误伤事件。Attack 太慢可能漏掉鼓击起音；太快又可能产生点击或失真。Hold 保持开门，Release 让关闭过程更平滑。不同产品的 Hold 计时定义并非完全一致：Ableton Live 12 Gate 描述为跌破阈值后进入 Hold；FabFilter Pro-G 描述为超过阈值后最少保持全开。不能把同一数字想当然当成相同时间窗。

另一个纯算术例子：假设某一门限器在 t=120 ms 已满足关闭条件，随后 Hold 40 ms，Release 80 ms，并假定中途没有再触发，则衰减从 160 ms 开始，到 240 ms 达到设定衰减量。它只画出示例控制时序，不预测 Pro-G 的实际包络；Pro-G 的时间行为受节目内容影响。真正调节时，先确认有效事件保留下来，再缩短余下输入。

## 参数不是越狠越好
Threshold 先寻找有效事件与无用段之间的分界。若两者电平重叠，单凭电平无法可靠分开，不应继续把阈值越抬越高。鼓组可考虑 detector 的频率选择、外部侧链、手工编辑或 Send automation。侧链仅是判断开关的控制信号，不是自动加入混响的音频；detector EQ 也不等于对送入 Reverb 的信号做 EQ。

Range 决定最大衰减，而不是门是否具有选择力。Pro-G 的 Range 设为 20 dB 时，最大衰减为 20 dB；一个 −40 dBFS 的输入样本若恰好处在最大衰减状态，输出是 −60 dBFS。它不是静音，后级混响仍可能收到微弱能量。较温和的 Range 或 downward expansion 可以保留更自然的衔接，但需试听。

真实对象采用 FabFilter Pro-G 官方媒体包截图。截图能证明 Threshold、Ratio、Range 和 Attack、Release、Hold 等控件的位置；不能证明教程数值，不能当作当前版本截图。媒体包文件时间为 2015 年，确切软件版本及组件未标明。Pro-G 当前手册说明 hysteresis 已按风格内建，不要在截图上虚构一个可调 Hysteresis 旋钮。

## 实际试听顺序
1. 先旁路混响，只听 Gate 后、Reverb 前的送入信号。确认弱音、字尾、装饰音没有被意外丢失；原轨 Dry 不应改变。
2. 恢复混响，只听 Wet，听起音是否完整、尾部是否连贯、噪声是否仍不断激励空间。
3. 回到整首编曲，以接近的主观响度 A/B。不要因为 Wet 变小就自动认定更清楚；必要时重新调 Return 电平。
4. 若输入 Gate 后尾巴仍太长，检查 Reverb 的衰减设置。如果想让 Wet 在指定时刻终止，另用后级 Gate 或自动化。
5. 对人声气息、弦乐延音、柔弱鬼音特别谨慎：这些可能正是表达的一部分。有效事件与噪声不易分离时，手工选择往往更可靠。

最后的目标并非把所有尾音剪掉，而是决定哪些声音值得进入空间，再让空间完成自己的衰减。

## 方法、边界与可重复操作
本报告不是一组插件实测。没有提供原始音频、工程文件或听音环境，因此不能报告噪声减少百分比、混响清晰度提升、具体门限器的阶跃响应或通用最优参数。所有坐标图都是为了隔离变量而构造的解析示意。

本篇采用三层证据：厂商手册确定产品定义；信号链运算解释前后次序；试听清单给出待实际音频验证的操作。三者不能互相代替。信号流的简化写法为前级 y=R(g·x)，后级 y=g·R(x)。R 代表有记忆的混响系统，g 代表随时间变化的门限器增益。这不是完整的插件建模；检测延迟、平滑、非线性、频率响应与调制会令实际结果更复杂。

构造示例的前提必须一起保留：输入检测包络与音频瞬时采样不是同一概念；开门之后才讨论 −27 dBFS 保持开门；−32 dBFS 只满足关闭条件，仍可能经过 Hold 和 Release；Range 的 −40→−60 dBFS 只在最大衰减20 dB已达到时成立。它没有证明混响输出也会下降20 dB，因为混响含有先前输入留下的能量。

用于实际录音的可重复检验建议：复制一小段同时含强击、弱击、停顿和串音的素材；固定混响算法、衰减、预延时与 Return 电平；比较 Gate旁路和启用状态；记录每个漏触发与误触发点。听音时保留全编曲场景，必要时另做响度接近的版本。一次只改变一个参数；将检测信号、Gate输出与Wet返回分别录出，才有条件追溯是触发判断、输入包络还是混响设置造成差异。不要把这份建议写成已经完成的实验。
