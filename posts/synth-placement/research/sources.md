# 合成器空间摆位的一手来源

全部来源为官方手册、厂商原始示范或学会原始讲义。网页当前内容已核对。产品数值仅支持其自身实现。

- S1 Ableton Live 12 Manual, Mixing 18.1、18.4。Pan 两种模式、Send 和 Pre/Post 路由。https://www.ableton.com/en/live-manual/12/mixing/
- S2 Ableton Live 12 Manual, Audio Effect Reference 29.40 Utility。Width、Mono、Balance。https://www.ableton.com/en/live-manual/12/live-audio-effect-reference/#utility
- S3 Apple Logic Pro for Mac User Guide, Set channel strip pan or balance positions。Balance 与 Stereo Pan。https://support.apple.com/guide/logicpro/set-channel-strip-pan-or-balance-positions-lgcpbc21a438/mac
- S4 FabFilter Pro-R 2 Help, Main controls。Predelay、Distance、Brightness、Mix 的产品定义。https://www.fabfilter.com/help/pro-r/using/maincontrols
- S5 Ableton Live 12 Manual, Reverb 29.32。Early Reflections、Diffusion Network、Predelay 与 Decay。https://www.ableton.com/en/live-manual/12/live-audio-effect-reference/#reverb
- S6 iZotope, What Is Mix Depth? How to Create Front-Back Space。厂商制作示范，支持电平、频谱、空间对比作为创作方法，不支持固定距离或保证效果。https://www.izotope.com/community/blog/what-is-mix-depth-how-to-create-front-back-space
- S7 iZotope, Reverb pre-delay explained: how to avoid a muddy reverb sound。Nick Messitte 的厂商实作示范。https://www.izotope.com/community/blog/reverb-pre-delay
- S8 Ville Pulkki, AES Tutorial 26, Applications of Binaural Psychoacoustics in Audio。讲义 PDF 第 49–56 页的听觉距离讨论；房间中的 DRR、声源特性及听者经验。https://www.aes.org/technical/documentDownloads.cfm?docID=551
- S9 FabFilter Pro-G Help, Mid/Side processing。M/S 的和差编码与可逆性；本文缩放约定另行明确。https://www.fabfilter.com/help/pro-g/using/midsideprocessing
- S10 iZotope Ozone 8 Help, Imager。相关度与单声道兼容性，明确这是 Ozone 8 文档，不借用其数值指导其他版本。https://downloads.izotope.com/docs/ozone8/imager/index.html

## 引用边界

原理解释、代数、构造示例和试听步骤分别标注。未取得输入音频，不存在试听实测、真实频响或真实房间距离估计。官方界面图只证明控件和当时截图状态。厂商示范效果并不保证应用于任意合成器也相同。
